PMP1 Redesign

P-on を PC1 の規則（グリッド・無彩色・信号オレンジ 1 色・極細の罫線）で組み直し、名前を PMP1 に変えた案です。v2 ではロゴとアプリアイコンのドットはそのままに、ボタン・スライダー・再生時間・ファイルアイコンを、すき間のないピクセルアートの SVG に描き直しました。窓の面は従来どおり Windows のアクリルの上に半透明で塗り、デスクトップが透けます。罫線やスライダーの溝は墨の半透明にしてあるので、どの壁紙でも同じ階調に見えます。下の壁紙と透過率を切り替えて確かめてください。再生・音量・シーク・ループ・シャッフル・自動調整・ロゴ（情報パネル）は操作できます。

    H決めていただきたいこと

    1. 改名の範囲: 画面上の名前・ウィンドウ名・インストーラーの製品名は PMP1 にします。ただしライブラリの保存フォルダ名（今は「P-on」）、GitHub のリポジトリ名（自動更新の配信元）、Windows のアプリ ID を変えると、既存の利用者のライブラリが見えなくなったり自動更新が途切れたりします。これらは据え置き（中身の識別子だけ P-on のまま）でよいですか。
    2. ナイトモード: PC1 は明るい 1 種類だけですが、P-on にはナイトモードがあるので、反転した配色で残す案にしています（上の Night で確認できます）。残しますか。
    3. アクセント: 深緑をやめて信号オレンジ 1 色にします。使うのは再生中の曲の印・オンのトグル（自動調整・ループ・シャッフル・最前面）・ロゴの「1」だけです。
    4. ファイルアイコン: 拡張子ごとの色分けをやめ、同じ図柄に拡張子のドット文字を添える形にしています。色分けを残したい場合は、メーターの柱をグレーの濃淡で変える案も作れます。
    5. アプリアイコン: 今の葉の写真をやめて、ドットのロゴだけにします。
    6. 文字の大きさ: 上の E の寸法でよいですか（もう一段小さくすることもできます）。
    7. バージョン: 名前が変わるので 1.5.0 にする想定です。スマホ版（Android / iOS）の表示名も PMP1 にしてよいですか。
