# P-on

手元の音楽ファイルを、自分の手で並べて聴くための Windows 用オーディオプレイヤー。

取り込んだ曲はアルバム・シングル・プレイリストという「棚」に並びます。
タグが無い音源でも、あとから名前やジャケットを付けて整えられます。

[**ダウンロード（最新版）**](https://github.com/Purukichi/P-on/releases/latest)

## できること

- **ドラッグ&ドロップで取り込む** — ウィンドウに音楽ファイルを落とすだけ。タグとジャケットは自動で読み取ります
- **アルバム / プレイリストで並べる** — 下段の「棚」にカードとして並び、掴んで運べます
- **再生キュー** — 聴きたいものを寄せ集めて、その場かぎりの並びを作れます
- **曲情報をあとから編集** — タイトル・アーティスト・アルバム名を直接書き換えられます。タグの無い音源でも困りません
- **ジャケットの二階建て** — 「アルバム共通」と「その曲だけ」を別々に持てます
- **ミニプレイヤー** — ジャケットだけを見せる小さな窓。常に手前に浮かせておけます
- **ナイトモード** — 明るい / 暗いを切り替えられます
- **自動更新** — 新しい版が出ると自動で受け取ります

対応する音声形式は **MP3 / WAV / FLAC / M4A / AAC / OGG / Opus / WebM**、
ジャケット画像は **JPEG / PNG / WebP / GIF / BMP** です。

## インストール

1. [Releases](https://github.com/Purukichi/P-on/releases/latest) から `P-on-<版>-x64.exe` をダウンロードします
2. 実行します。管理者権限は要りません。現在のユーザーにだけ入り、デスクトップとスタートメニューにショートカットができます
3. インストールが終わるとそのまま起動します

対応環境は **Windows 10 / 11（64bit）**です。

### 「WindowsによってPCが保護されました」と出たら

「詳細情報」→「実行」で進めてください。

この警告は Microsoft が発行元を確認できていないときに出るもので、
個人が作ったアプリでは通常のことです。
exe には電子署名を付けてあるので、進める前に**中身がすり替えられていないか**を確かめられます。

exe を右クリック → プロパティ → **デジタル署名**タブ に
`Yushi Hiyama` と出ていれば、配布したときのままのファイルです。
このタブが無い、または別の名前になっている場合は実行しないでください。

### アンインストール

Windows の「設定」→「アプリ」→「インストールされているアプリ」から `P-on` を削除します。
**取り込んだ音源は消えません**（[データの保存場所](#データの保存場所)にそのまま残ります）。

## はじめかた

1. **音源を入れる** — ウィンドウに音楽ファイルをドラッグ&ドロップします
2. **カードをクリック** — 下段の棚にカードが並びます。クリックすると頭から再生します
3. **並べ替える** — 右クリックで名前やジャケットを直せます

取り込んだファイルはライブラリフォルダに**コピー**されます。
元のファイルを移動・削除しても再生は続けられます。

---

## 画面の見かた

画面は 3 つに分かれています。

| 場所 | 何があるか |
| --- | --- |
| **上** | 再生中の曲。ジャケット、曲名、シークバー、再生ボタン |
| **右** | 再生キュー（いま鳴らしている並び）。曲順の入れ替えと編集もここ |
| **下** | 棚。ライブラリの中身がカードで並びます |

### 棚に並ぶ 3 種類

| 種類 | 中身 |
| --- | --- |
| **プレイリスト** | 自分で作ったもの |
| **アルバム** | アルバム名が同じ曲をまとめたもの |
| **シングル** | アルバム名が無い曲（1 曲で 1 枚扱い） |

検索欄の右にある切り替え（音符 / CD）で、**曲単位**の並びにもできます。
アルバムの中の 1 曲だけをキューへ運びたいときに使います。

棚は縦に折り返さず、横へ並んでいきます。**マウスホイールの上下がそのまま横送り**になります。

「もっと見る」を押すと棚が広がり、上の再生画面は 1 行に畳まれます。

## 音源を取り込む

| やりかた | 操作 |
| --- | --- |
| ドラッグ&ドロップ | ウィンドウのどこにでも落とす |
| ボタンから | 棚の「音源を追加」 |

複数のファイルをまとめて落とせます。対応形式でないものは読み飛ばします。

> フォルダごと落とすことはできません。中のファイルを選んで落としてください。

埋め込みタグ（曲名・アーティスト・アルバム・ジャケット）は取り込み時に読み取ります。
タグが無いファイルは**ファイル名が曲名**になり、シングルとして棚に並びます。
あとから[まとめてアルバムにする](#複数をまとめてアルバムにする)ことができます。

## 再生する

| やりたいこと | 操作 |
| --- | --- |
| 頭から再生 | 棚のカードをクリック |
| 曲を選んで再生 | カードを右クリック → 出てきた一覧から曲を選ぶ |
| 再生 / 一時停止 | 再生ボタン、または **Space** キー |
| 停止 | 停止ボタン（頭に戻ります） |
| 前 / 次の曲 | 前後のボタン |
| 早送り・巻き戻し | シークバーを掴む |
| 音量 | 左上のスライダー。**数字をダブルクリック**すると 0〜100 を直接入力できます |

### ループとシャッフル

操作ボタンの右にある 2 つのボタンです。設定は次回起動時も覚えています。

| ボタン | 押すたびに |
| --- | --- |
| **ループ** | しない → キュー全体をループ → 1 曲だけループ |
| **シャッフル** | 順番どおり → シャッフル |

## 再生キューを組む

右のリストが「いま鳴らしている並び」です。棚から寄せ集めて自由に組めます。

| やりたいこと | 操作 |
| --- | --- |
| 束ごと足す | 棚のカードを右のリストへドラッグ（末尾に足されます） |
| ドラッグせず足す | カードを右クリック →「再生キューに追加」 |
| 1 曲だけ足す | 右クリックの曲一覧で、行の **＋** を押す |
| 1 曲抜く | リストの行の「外す」 |
| 空にする | リストの「空にする」 |
| 曲順を入れ替える | リストの「編集」中に、行の左の掴み手を上下へドラッグ |

リストの見出しは、鳴らしているアルバムやプレイリストの名前になります。
寄せ集めて組んだときは「再生キュー」と出ます。

> キューの並べ替えはその場かぎりです。
> アルバムとプレイリストの曲順を変えたいときは、そのカードを開いてから並べ替えてください（順番が保存されます）。

## 整理する

棚のカードは**右クリック**がすべての入口です。
種類ごとに、できることが変わります。

| 右クリックした先 | 出てくるもの |
| --- | --- |
| プレイリスト | 先頭から再生 / キューに追加 / ジャケットを変更 / 名前を変更 / 削除 |
| アルバム | 先頭から再生 / キューに追加 / ジャケットを変更 / アルバム名を変更 / アルバムのアーティストを変更 / 収録曲のアーティストをまとめて変更 / アルバムごと削除 |
| シングル | 先頭から再生 / キューに追加 / 楽曲情報を編集 / この曲を削除 |

2 曲以上あるものは、メニューの下に収録曲の一覧が付きます。
行をクリックするとその曲から再生、**＋** ならキューに足すだけです。行を掴んで運ぶこともできます。

### プレイリストを作る

| やりかた | 操作 |
| --- | --- |
| 空のものを作る | 棚の「**＋ プレイリスト**」。名前を付けてから、曲を運び込みます |
| 選んでから作る | カードを複数選び、上に出るバーの「プレイリストにする」 |
| 2 つを重ねて作る | 棚のカードを、別のアルバム / シングルのカードへ重ねる |
| 既存のものに足す | 棚のカードを、プレイリストのカードへ重ねる |
| 1 曲だけ足す | 右のリストの行を、プレイリストのカードへドラッグ |

### 複数をまとめてアルバムにする

タグの無い音源はシングルとして入ります。
まとめたい曲を選び、上に出るバーの「**アルバムにまとめる**」を押すと、アルバム名を一度に書き込めます。

### 複数選ぶ

| やりかた | 操作 |
| --- | --- |
| ひとつずつ | カードのチェックボックス、または **Ctrl + クリック** |
| なぞって選ぶ | **Shift + ドラッグ**（なぞったぶんが足されます） |
| 選択を解除 | 選択バーの「選択を解除」 |

選んでいる間は、上に「アルバムにまとめる」「プレイリストにする」「削除」のバーが出ます。

### 曲情報を編集する

| やりたいこと | 操作 |
| --- | --- |
| 1 曲だけ直す | 右のリストの行にマウスを乗せて「編集」 |
| まとめて直す | 右のリストの「編集」。タイトル / アーティスト / アルバムを直接入力できます |
| アルバム名を変える | アルバムのカードを右クリック →「アルバム名を変更」 |

編集欄は**入力欄から離れた時点で保存**されます（Enter でも確定します）。Esc で取り消せます。

> アルバムには**2 種類のアーティスト**があります。
> 「アルバムのアーティストを変更」はアルバムの表記（`V.A.` など）だけを変え、収録曲には触れません。
> 収録曲そのものを直したいときは「収録曲のアーティストをまとめて変更」を使ってください。

### 検索する

棚の左上の検索欄から探せます。アルバム名・プレイリスト名・曲名・アーティスト名にあたります。**×** で解除します。

再生中の表示や一覧に出ている**アーティスト名をクリック**すると、その名前で棚を検索します。

### 削除する

| やりたいこと | 操作 |
| --- | --- |
| カードごと消す | カードを右上のゴミ箱へドラッグ、または右クリック → 削除 |
| まとめて消す | 選んでから、選択バーの「削除」 |
| 1 曲だけ消す | 右のリストの行を、右上のゴミ箱へドラッグ |

いずれも確認が出ます。**音源ファイルとジャケットも一緒に消えます**（元に戻せません）。

## ジャケット

ジャケットは「アルバム共通」と「その曲だけ」の**二階建て**です。

| | どこで設定するか | 効く範囲 |
| --- | --- | --- |
| **アルバム共通** | カードを右クリック →「アルバムのジャケットを変更」<br>再生中なら、ジャケットの上の札をクリック / 札に画像をドロップ | そのアルバムの全曲 |
| **その曲だけ** | ジャケット枠をクリック / 枠に画像をドロップ / 編集ダイアログ | その 1 曲だけ（アルバム共通を上書き） |

再生中の画面では、ジャケット枠のすぐ上に札が出ます。
札には、いま鳴らしているアルバム / プレイリストの名前が出ます。

**落とす場所で行き先が変わります。** 枠に落とせばその曲だけ、札に落とせばアルバム側です。
アルバム再生中でも、枠に落としたぶんはその曲にしか付きません。

取り込み時、アルバム名を持つ曲の埋め込み画像は**アルバム共通**として保存されます。
アルバム名の無い曲（シングル）の画像は、その曲個別のジャケットになります。

## アーティスト名

アーティスト名は `A, B, C` のように区切ると**複数名**として扱います。
区切りとして認識するのは `,` `、` `／` `/` と `feat. ` です。

- 検索ではどの名前からでも引けます（`B` だけでもヒットします）
- 画面に出る名前は 1 人ずつのリンクになり、クリックするとその名前で棚を検索します
- アルバムの副題には、収録曲に出てくるアーティストをすべて並べます（同じ名前は 1 度だけ）

## ミニプレイヤー

右上のミニプレイヤーアイコンから切り替えます。
ジャケットを窓いっぱいに見せる、正方形の小さなプレイヤーです。

| やりたいこと | 操作 |
| --- | --- |
| 操作面を出す | 窓にマウスを入れる（普段はジャケットだけが見えています） |
| 窓を動かす | ジャケットの面を掴んでドラッグ |
| 大きさを変える | 窓の縁をドラッグ（外周 8px が掴みしろ）。形は常に正方形のままです |
| 常に手前に出す | ピンボタン。**既定は有効**。切ると他の窓に隠れます |
| メインに戻る | **−** ボタン |
| アプリを終了する | **×** ボタン |

再生・一時停止・前後の曲・シークバー・音量は、操作面からそのまま操作できます。

**切り替えても音は途切れません。** ミニプレイヤーは表示と操作だけを担当していて、
音を鳴らしているのは隠れたメインウィンドウのままです。

## 見た目を変える

| やりたいこと | 操作 |
| --- | --- |
| ナイトモード | 右上の 月 / 太陽 アイコン（次回起動時も覚えています） |
| 棚の表示 | 検索欄の右の グリッド / リスト 切り替え |
| 棚を広げる | 「もっと見る」 |

ウィンドウは背後のデスクトップがうっすら透けます（Windows 11 のアクリル素材を使っています）。
透け具合はアプリ側で固定しているため、変更はできません。

## データの保存場所

```
ドキュメント/P-on/
├── library.json   曲情報とプレイリスト
├── audio/         取り込んだ音源（元のファイル名のまま）
└── covers/        ジャケット画像
```

右上のフォルダアイコン（**保存フォルダを開く**）からエクスプローラーで開けます。

### 保存先を変える

右上の「フォルダ＋矢印」アイコンから変更できます。
切り替えるときに、いまのデータを**移動する / コピーする / 何もしない**を選べます。

音源が増えて Cドライブが手狭になったときや、外付けドライブに置きたいときに使ってください。

> アプリの外からこのフォルダの中身を消しても、**起動中は反映されません**。
> ファイルを直接いじったときはアプリを再起動してください。

## 自動更新

インストール版は起動から数秒後に新しい版がないか確認し、
見つかると裏でダウンロードしてから再起動をうながします。
「あとで」を選んでも、次にアプリを終了したときに適用されます。

いますぐ確かめたいときは、左上のブランドマーク →「**更新を確認**」。
いま入っている版もここで確認できます。

## 困ったときは

**同じ曲が 2 つ並んだ**
同じファイルを 2 回取り込むと、2 曲として登録されます（重複の判定はしていません）。
片方をゴミ箱へドラッグして消してください。

**フォルダの中身を消したのに、まだ曲が残っている**
曲情報はアプリの起動時に一度だけ読み込みます。アプリを再起動してください。

**アルバムがばらばらのシングルとして入った**
その音源にアルバム名のタグが無いためです。
まとめたい曲を選んで「アルバムにまとめる」を押すと、一度にアルバム名を書き込めます。

**ジャケットを変えたのに 1 曲だけ変わらない**
その曲に個別のジャケットが設定されています（個別のほうがアルバム共通より優先されます）。
右のリストの行から「編集」を開き、ジャケットを外してください。

**更新が来ない**
リリースの公開直後は反映まで少し時間がかかることがあります。
左上のブランドマーク →「更新を確認」で手動確認できます。

**ミニプレイヤーの操作面が出ない**
窓の中にマウスを入れている間だけ出ます。ジャケットだけの状態が既定です。

### まだできないこと

- イコライザー・音質の調整
- 歌詞の表示
- macOS / Linux 版（Windows 専用です）

## 開発者向け

Electron + electron-vite。フレームワークを使わない、素の HTML / CSS / JavaScript 構成です。

```bash
npm install
npm run dev        # 開発中の起動（保存すると即反映）
npm run build:win  # Windows 用インストーラを release/ に作る
```

| 場所 | 中身 |
| --- | --- |
| `src/main/` | Electron メインプロセス。ウィンドウ、ファイルの取り込み、保存 |
| `src/preload/` | レンダラーへ公開する API（`window.hamon`） |
| `src/renderer/src/core/` | DOM に触らないロジック（再生・キュー・ライブラリ） |
| `src/renderer/src/ui/` | 画面の更新だけを担当 |
| `src/renderer/src/styles/` | テーマとパーツ別の CSS |

配布する exe には Authenticode の署名を付けています。設定は `electron-builder.yml` を参照してください。
